# Nicht produktiv installieren

Dieses Paket ist ein **Engineering-Handoff für ZEC V14 WP2** und kein installierbarer Controller-Release.

Insbesondere:

- `APP_VERSION`/`APP_BUILD_ID` bleiben V13.0.3;
- es gibt noch keinen produktiven V14-Rebuild-/Cutover-Installer;
- eine vorhandene V2-Messdatenbank wird bewusst nicht automatisch migriert;
- Graph V14 UI/Query-Service und weitere Arbeitspakete fehlen noch.

Die enthaltene Source darf nur als verifizierte Entwicklungsbasis für den nächsten freigegebenen V14-Arbeitsblock verwendet werden.
