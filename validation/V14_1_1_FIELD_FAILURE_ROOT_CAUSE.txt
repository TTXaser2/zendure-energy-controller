Root cause:
  V14.1.0 package preflight executed package v14_cutover.py from the staging CWD.
  The productive config intentionally uses relative MEASUREMENT_LOG_DIR=logs and
  empty MEASUREMENT_DB_PATH. resolve_measurement_db_path therefore resolved the
  DB below the staging CWD instead of the installed runtime root.

V14.1.1 correction contract:
  - verify/preflight support explicit --runtime-root
  - installer pins runtime root to /opt/zendure-controller
  - diagnostics pin runtime root to dirname(config)
  - existing V3 verify is read-only and does not call connect_graph_core()
  - regression reproduces staging-CWD failure and verifies fixed lookup
